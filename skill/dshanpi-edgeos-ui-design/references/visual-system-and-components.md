# 视觉系统与组件指南

## 画布与安全区

- 基准画布为 640 × 480 横屏。
- 桌面状态栏高度采用 44 px；应用内容避开状态栏和屏幕边缘。
- 常规页面外边距使用 8、12 或 16 px，组件内部间距以 4 px 倍数递进。
- 不依赖鼠标 hover；所有信息在默认、按下、选中和禁用状态中完整表达。
- 列表内容溢出时使用垂直滚动，避免把按钮压缩到不可触摸尺寸。

## 色彩

沿用低饱和浅色桌面和高对比正文：

| 角色 | 推荐起点 | 用法 |
| --- | --- | --- |
| 页面背景 | `#F2F2F7` / `#F4F7FB` | 系统页和工具页背景 |
| 表面 | `#FFFFFF` | 卡片、标题栏、对话框 |
| 主文字 | `#172033` / `#111827` | 标题和关键数值 |
| 次文字 | `#64748B` / `#6B7280` | 描述和辅助状态 |
| 主操作 | `#007AFF` | 选择、完成、下载等主操作 |
| 成功 | `#25A55F` | 已连接、已完成 |
| 警告 | `#D68A00` | 需要关注但可恢复 |
| 危险 | `#FF3B30` / `#D93025` | 删除、失败、破坏性确认 |

页面可使用应用自己的柔和强调色，但正文对比度和状态含义保持一致。不要只用红绿区别状态，应同时提供图标或文字。

## 字体层级

- 页面主标题：Montserrat 28 或与 CJK 视觉重量相当的字体。
- 卡片标题和关键操作：16–20 px。
- 正文和列表：14–16 px。
- 辅助说明：12–14 px，但不得用于关键错误或主要操作。
- 英文默认使用 LVGL Montserrat；中、繁、日使用 `ui_font_source_han_20`。
- 数字、波特率、IP、版本和终端内容可使用英文/等宽风格，但其标签仍应本地化。

长文本优先调整容器和换行，不以过小字体隐藏布局问题。

## 桌面图标

- 桌面使用三列弹性换行网格，当前卡片约 184 × 184 px、图形区域约 108 × 108 px。
- 图标图形来自统一 Material 风格资源，使用柔和背景和低强度阴影。
- 应用名位于图标下方并居中；四种语言都必须在两行以内清晰识别。
- 装饰子对象移除 CLICKABLE 和 SCROLLABLE，让整个卡片处理手势。
- 禁用 `SCROLL_ON_FOCUS` 与不必要的 pressed 缩放，避免点击时网格跳动。

## 顶部栏与返回按钮

- 标题栏保持固定高度和纯色表面，不随内容滚动。
- 返回按钮置于左上，视觉尺寸 48–56 px，并把扩展点击区域覆盖到 x=0、y=0 边缘。
- 主标题从返回按钮后开始，不能与状态或右侧操作重叠。
- 右上操作最多保留一到两个高频动作；更多操作进入内容区或对话框。

## 卡片与列表

- 一张卡片只表达一个设置组、任务或媒体项目。
- 主标题、状态/说明、操作按视觉层级排列；不要让整卡文字拥有相同字重和颜色。
- 列表行的整行可点击，内部图标和标签不单独抢占事件。
- 选中态同时使用背景、勾选或边框，不仅改变文字颜色。
- 空列表显示原因与下一步，例如“未发现网络—重新扫描”。

## 按钮

- 最小触摸目标 44 × 44 px；常用圆形按钮建议 48–56 px。
- 主按钮使用明确动作动词，如“下载并更新”“连接”“发送”。
- 危险按钮使用红色语义并配确认对话框。
- 忙碌期间禁用触发按钮，显示当前进度；不能通过连续点击启动多个工作线程。
- 图标按钮若含义不够普遍，应配文字或相邻标签。

## Dropdown、Picker 与对话框

- Dropdown 适合短而互斥的选择，如波特率、帧格式、模型任务。
- 长选项、需要说明的选项或语言选择使用全屏/卡片 Picker。
- LVGL dropdown 展开列表属于 screen 层；页面退出前必须调用 `lv_dropdown_close()`。
- 对话框遮罩阻止点击穿透，卡片中提供标题、影响说明、取消和确认。
- 默认焦点放在安全操作；破坏性确认不应成为唯一大按钮。

## Toast、加载与状态条

- Toast 用于短暂、无需决策的结果，展示后自动消失且不阻塞触摸。
- 加载 overlay 用于必须等待的资源切换；有取消能力时应明确提供取消。
- 持续任务优先展示阶段和数值进度；没有可信进度时展示阶段文案和超时结果。
- 错误状态至少说明操作对象、失败阶段和用户下一步。

## 动效

- 动效用于解释状态变化，不作装饰性循环。
- 页面切换和加载反馈保持短促，实时相机与推理运行时降低动画成本。
- 滚动保留动量和边缘弹性，但不要强制行吸附；小屏触摸下自由滚动更易控制。
